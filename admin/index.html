ℹ️ How to connect Google Analytics
1
Open Google Looker Studio
Go to lookerstudio.google.com and sign in with the same Google account that owns your Analytics property.
2
Create a new report
Click Create → Report. When prompted to add a data source, select Google Analytics and connect your New Money Muse property (G-GVSW4WXWLK).
3
Add these charts to your report
Use Insert → Chart to add:
  • Scorecard: Sessions (this month)
  • Scorecard: Active users
  • Scorecard: New users
  • Time series: Sessions over time
  • Table: Top pages by page views
  • Pie chart: Traffic by source/medium
4
Get the embed URL
Click File → Share → Embed report. Copy the URL from the iframe src attribute — it looks like:
https://lookerstudio.google.com/embed/reporting/...
5
Paste the URL below and save
Your Analytics dashboard will display right here in the admin panel — live data, auto-refreshing.
